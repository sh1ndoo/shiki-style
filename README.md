# shiki-style

Кастомная тёмная тема для Shikimori с акцентным цветом `rgb(152, 132, 165)`.

## Особенности
- Тёмный фон страниц и меню
- Акцентный цвет — мягкий пурпурно-серый `#9884a5`
- Анимированный фон — чёрно-белые цветы
- Без RGB-эффектов
- Скруглённые элементы, кастомный скроллбар

## Установка
Используйте расширение для браузера (Stylus, Stylish и т.п.), вставив содержимое `css/main.css`.
